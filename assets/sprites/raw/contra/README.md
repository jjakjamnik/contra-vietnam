# Contra — extracted sprite samples

Raw PNG sprite compositions extracted from the original Contra (US) NES graphics and imported from [vermiceli/nes-contra-us](https://github.com/vermiceli/nes-contra-us/tree/main/docs/sprite_library/contra_sprites). Original sprite IDs are retained in filenames. The upstream [sprite library index](https://github.com/vermiceli/nes-contra-us/blob/main/docs/sprite_library/README.md) maps IDs to the game’s sprite table. This is an initial subset; the full library contains 233 PNG/GIF files, not all imported yet.
